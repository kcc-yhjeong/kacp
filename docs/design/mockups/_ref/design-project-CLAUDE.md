# KACP 시안 작업 규칙

- 기준 문서: uploads/01-screens(-9972beae).md, uploads/02-design-system.md. shadcn neutral, 흑백, 카드 테두리만, 상태는 outline 배지 + 색 점.
- 공용 DC: AppHeader(C-00), Icon(Lucide), Stepper, DriveTree. 모든 화면은 AppHeader 사용.

## 앱의 두 사본 (모든 앱 관련 화면에 적용)
- 작업본: Private, `앱--팀.kacp.cloud`, 팀만, 에이전트 수정 즉시 반영. 배지 = 회색 채움 "Private · 팀만"(Lock)
- 공개본: Public, `앱.kacp.cloud`, 전 사원, 승인 시점 스냅샷 v1/v2/v3…. 배지 = 검정 채움 "Public v2"(Globe)
- Public이 되어도 작업본은 남는다. 공개본 갱신은 "업데이트 요청 → 승인"뿐. 두 사본을 항상 따로 보여준다.
- "공개 중지" = 공개본만 삭제, 작업본은 남음.
- 잠듦: 오래 안 쓰면 잠들고 접속 시 자동으로 깨어남. 배지 = outline + 회색 점 "잠듦 · 접속하면 켜져요"
- 업데이트 대기: outline + 주황 점 "업데이트 대기 v2→v3"
- 두 사본의 데이터는 분리.

## 부서(조직) — 팀과 별개
- 부서 = 실제 사내 소속, 트리(최대 10단계, 샘플은 6단계 KCC정보통신 > 경영지원본부 > 인사부 > 인사팀 > 채용파트 > 신입채용셀). 한 사람 = 부서 하나.
- 팀 = 에이전트 공유 작업 단위. 여러 부서 섞임, 한 사람 여러 팀.
- 사원 화면에서 부서는 이름 옆 회색 작은 글씨만("홍길동 · 영업1팀"), 동명이인 구분용. 관리자 표는 부서 열(말줄임 + 전체 경로 툴팁).
- 아이콘: 조직 = Building2(Icon n="building"), 가져오기 = FileUp("file-up"). 트리 들여쓰기 단계당 12px, 브레드크럼 5단계 초과 시 가운데 … 접기.
- 관리자 사이드바 그룹: 대시보드 / 사람(조직, 사용자) / 팀과 에이전트 / 심사·승인 / 운영.
- 헤더 전사 메뉴에 "지식" 추가 예정 — 자리만 확보(min-width), 아직 그리지 않음.

## 남은 반영 사항 (관리자 화면 만들 때)
- A-01: "실행 중 앱" 카드 → "작업본 n · 공개본 n"
- A-05 앱 탭: U-07과 같은 열, 버튼 "공개본 강제 중지"
- A-09: 요청 종류 배지 "새 공개"/"업데이트 v2→v3", 업데이트 상세(변경 내용 + 파일 변경 목록 추가·수정·삭제 + 작업본(새 버전)·공개본(현재) 열기), 공개 중인 앱 탭에 버전 열, 강제 중지에 "작업본에는 영향 없음"
- A-10 운영: 앱 유휴 정지 시간(작업본/공개본 각각), 팀당 동시 실행 작업본 수
